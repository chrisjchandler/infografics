- [Hydra Character Sprite](https://rarelionart.itch.io/hydra-character-sprite): paid listing exposes no public modification/reuse license.
- [Sprite Pack – Mythological Monsters](https://ariaw.itch.io/monster-sprite-pack-mythological): no license displayed.
- [Ancient Greek Mythology – Top-Down Pixel Art Tileset](https://sakpix.itch.io/ancient-greek-mythology-top-down-pixel-art-tileset-32x32): unclear adaptation terms; listing marked AI-assisted.
- [Greek Mythology Pixel Art Collection](https://neopixelboyco.itch.io/greek-mythology-pixel-art-collection): restrictive custom license does not clearly authorize derivative sprite edits.

## Required attribution record fields

For every non-CC0 asset, store:

- asset title;
- creator;
- canonical source URL;
- exact license and license URL;
- local source archive checksum;
- original filename;
- modification description;
- date retrieved;
- required attribution text;
- ShareAlike status.

CC BY adaptations must preserve creator, title/source, license, and change notice. CC BY-SA adapted artwork must be distributed under a compatible ShareAlike license; this does not automatically impose ShareAlike on unrelated application code.

## Recommended low-risk vertical slice

Sisyphus:

1. Use the CC0 Greek Hypaspist only as a proportion/palette base.
2. Use the public-domain Titian and Met references for a custom pushing silhouette.
3. Use the CC BY rolling rock as a timing/orientation basis or redraw eight original orientations.
4. Author the man+boulder contact as one coordinated 128×96 frame cell.
5. Preserve attribution if any portion of the CC BY rock remains in the final atlas.
