Infograf workflow infographic

A user can start with plain language, a spreadsheet, or a datasource, then turn the same underlying model into a live scene, a replayable timeline, and outbound hooks. This version uses database replication to make the workflow concrete.
mock data: DB replication lag / failover / hooks

Workflow

1

Ingest

Connect Prometheus, Graphite, OTEL, REST, CSV/XLSX, or a plugin connector.

2

Normalize

Metrics become canonical values, rates, deltas, lag, and events.

3

Author

Use WYSIWYG controls to define source, metric, thresholds, placement, and hooks.

4

Simulate

Drag the value slider, trigger events, and verify the scene without live data.

5

Render

SVG-first layout composes scene objects with animation cues and annotations.

6

React

Local visual effects stay separate from external hooks like PagerDuty or webhooks.
