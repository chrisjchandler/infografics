# Infografics Regression Audit

Date: 2026-09-02  
Scope: audit only; no application code was changed.

## Executive finding

The rescue work improved the backend data model, normalization, deterministic timestamp evaluation, and Graphite canonicalization. It nevertheless regressed the product as an authoring platform by replacing the pre-rescue multi-source studio with a Graphite-specific runtime and by leaving the new canonical scene state disconnected from the renderer.

The highest-impact failures are:

1. The visible source configurator lost Prometheus, OpenTelemetry, generic REST, CSV/XLSX, and raw/plaintext choices. All non-Graphite connectors are now labels marked `planned`.
2. The working browser-side CSV parser was removed.
3. The binding composer lost source, metric, target, placement, and X/Y offset controls. The replacement builder emits a fixed Graphite-to-`actorRoot.path_progress` YAML-shaped string.
4. The YAML text area is not a YAML editor or a round trip. Visual control changes overwrite it, manual edits are never parsed or validated, and the backend stores it as an opaque string.
5. `EvaluateScene` calculates normalized object properties, but `renderStage()` ignores `SceneState.Objects` and independently derives coordinates with `chartPoints()`. The canonical binding path therefore does not reach the visible object.
6. Sprite frames advance from an unconditional 120 ms `setInterval`; `AnimationSpeed` and binding animation specifications are ignored. This is timer-driven decorative animation.
7. X positions use sample index rather than elapsed time. Irregularly spaced samples are plotted and animated at equal distances despite the UI claiming “TIME ON X.”
8. Annotations are generated Graphite extrema/slope summaries, are always shown as a list, and are not filtered or rendered as active timeline scene events.

These are release-blocking regressions against the stated Infografics architecture. The canonical backend is useful work, but it currently terminates before the authoritative renderer.

## Capabilities improved rather than regressed

These changes should be retained during restoration:

- `model.CanonicalSeries`, `CanonicalPoint`, `CanonicalEvent`, `SceneBinding`, and `SceneState` establish a source-agnostic boundary.
- `Normalize()` and `MapNormalized()` implement clamping and inversion and reject `min == max`.
- `EvaluateScene()` reconstructs samples at a requested timestamp and derives delta, rate, acceleration, volatility, and active event windows.
- The Graphite scene path discovers metrics, converts datapoints to canonical timestamped series, and produces backend frames.
- Current pixel-art atlases are materially more presentation-ready than the pre-rescue procedural figures, and source/provenance documentation exists.
- Current timeline scrub/previous/next controls are more capable than the demonstrable pre-rescue playback surface.

These improvements do not cancel the regressions above. Restoration should connect and generalize them rather than reverting wholesale to the pre-rescue architecture.

## Test and review gaps

Current automated tests cover normalization/inversion, one X mapping, deterministic object/event counts, basic endpoint shape, Graphite timeline ordinal progress, range padding, and metric-slot selection. They do not cover:

- renderer consumption of `SceneState.Objects`;
- irregular timestamp → X mapping;
- normalized values through every supported scene property to the DOM/SVG;
- configured animation duration/easing/speed and deterministic sprite phase;
- preferred-direction trend behavior or first-frame trend semantics;
- expression parsing, threshold duration, invalid expressions, or dry-run actions;
- any non-Graphite source equivalence;
- CSV/XLSX/raw/REST/Prometheus/OpenTelemetry ingestion;
- event persistence and timeline-visible active windows;
- visual ↔ YAML ↔ API round trip;
- self-contained deterministic export;
- browser screenshots for healthy/rising/severe/incident/recovery states.

`go test ./...` could not be rerun in the restricted environment because required modules were absent from the local module cache and network access to `proxy.golang.org` was blocked. This is a verification limitation, not a test pass. The existing `docs/rescue-audit.md` reports that tests passed earlier after dependencies were downloaded, but that report predates the later Graphite scene/UI changes and is not a regression run for the current tree.

## Required restoration order

1. Recover the real Git repository metadata and identify the exact pre-rescue commit and hashes for each replacement above. Preserve this audit’s file-level findings when hashes are filled in.
2. Define and validate one versioned, source-agnostic document model for sources, scenes, bindings, expressions, events, actions, layout, animation, and assets.
3. Make the authoritative renderer consume `SceneState.Objects`, metrics, and active events without recomputing semantics.
4. Correct timestamp-based X mapping and add value → normalized → property → renderer integration tests.
5. Remove wall-clock decorative sprite behavior; derive clip, direction, speed, and deterministic phase from state and playback time.
6. Restore multi-source authoring and the confirmed CSV path, then recover/restore Prometheus, OpenTelemetry, REST, XLSX, and raw support according to history rather than relabeling them as future work.
7. Build the real expression/YAML round trip and safe action dry-run model on the shared schema.
8. Restore persisted events/annotations and synchronize them with replay, snapshot, and export.
9. Produce self-contained deterministic exports and run the actual UI with screenshot comparisons at representative states.

No implementation work should begin by deleting the new canonical engine or by restoring the old browser-side semantic duplication. The necessary correction is to complete the abstraction: adapters feed canonical data; expressions and bindings create deterministic scene state; the renderer and exporter consume that state.
